# FNAF_PPT
recreation of Five Nights at Freddy's 1 Custom Night using Power Point VBA. This was made by me in 2022 only for fun and study.


## ALWAYS keep the folder "FNAF 1jpg" at the same folder as "FNAF.1 (by-@davidkben).ppsm"

# KNOW ERRORS

### in case of the game crash (1° method):

follow the steps of this video if you don't have MACROS enabled:
https://www.youtube.com/watch?v=JUWyx7x9JMA

________________________________________
### in case of the game crash (2° method):

1. go back to main menu by clicking on that "X" located in the upper left corner;

2. exit the game and enter again;

3. start a night with all animatronics with 0 A.I.;

4. go back to menu again;

5. start a normal night with the values you want.
